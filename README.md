# A/B-тест рекламной кампании: есть ли инкрементальный эффект

**Вопрос:** приносит ли реклама дополнительные конверсии, и стоит ли её продолжать?

**Итог:** реклама даёт 7,7 дополнительной конверсии на 1000 пользователей (95 % CI [6,0; 9,4]). Продолжать стоит, если она окупается даже при нижней оценке.

**Данные:** [Marketing A/B Testing](https://www.kaggle.com/datasets/faviovaz/marketing-ab-testing) (Kaggle): 588 101 пользователь, группы `ad` и `psa`, сплит 96/4. Файл в репозиторий не входит: для запуска положить его в `../data/d2/marketing_AB.csv`.

## Результат
| Группа | Пользователи | Конверсии | Конверсия |
|---|---|---|---|
| `ad` | 564 577 | 14 423 | 2,555 % |
| `psa` | 23 524 | 420 | 1,785 % |

- Разница: +0,77 п.п. (95 % CI [0,60; 0,94]), относительная +43,1 % (95 % CI [30,0; 57,5]).
- Дополнительные конверсии: 7,7 на 1000 пользователей (95 % CI [6,0; 9,4]).
- z = 7,37, p ≈ 1,7·10⁻¹³.

## Вывод для продакта
1. Проверяли, даёт ли реклама дополнительные конверсии: сравнили 564 577 пользователей, видевших рекламу, и 23 524, видевших на тех же местах социальную рекламу.
2. Реклама дала 7,7 дополнительной конверсии на 1000 пользователей: 25,5 против 17,9, то есть примерно +43 %.
3. Случайностью это объяснить трудно. Реальный эффект, скорее всего, от 6,0 до 9,4 конверсии на 1000 пользователей.
4. Рекомендую продолжать, если реклама окупается даже при нижней оценке: затраты на 1000 пользователей < 6 × прибыль с одной конверсии. При среднем 24,8 показа на пользователя это значит, что прибыль с конверсии должна быть больше примерно 4,2 × цены 1000 показов.
5. Ограничения: в данных нет денег, дат и определения конверсии, заявленный сплит неизвестен, а проверить сопоставимость групп по признакам до показа нельзя.

## Как проверял
- **Дизайн:** единица рандомизации и анализа — пользователь, метрика — доля пользователей с `converted = True`. Контроль видит социальную рекламу на тех же местах, поэтому группы отличаются только содержанием объявления.
- **Данные:** одна строка — один пользователь, пропусков нет, пользователей сразу в двух группах нет. Выбросы `total_ads` (максимум 2065 при 99-м перцентиле 202) не удалял: признак измерен после начала показа, и чистка по нему могла бы сместить сравнение.
- **Критерий:** z-тест для двух долей и 95 % CI абсолютной и относительной разницы.

## Ограничения
- В данных нет денег, дат и определения конверсии.
- Заявленный сплит неизвестен, поэтому SRM проверить нельзя.
- Признаков, известных до начала показа, нет: сопоставимость групп держится на предположении, что разбиение было случайным.
- Доли пользователей по дню с максимумом показов расходятся до 2,6 п.п. (четверг: 14,0 % и 16,6 %).
